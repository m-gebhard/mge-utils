    FindInHierarchy(Transform, Func<Transform, Boolean>, Boolean)

    Finds all Transforms in the hierarchy of the given root Transform that match the specified filter.

    Declaration
    public static Transform[] FindInHierarchy(this Transform rootTransform, Func<Transform, bool> filter, bool includeInactive = false)
    Parameters
    Type Name Description
    Transform rootTransform

    The root Transform to search within.
    System.Func<Transform, System.Boolean> filter

    A function that defines the condition each Transform must satisfy to be included in the results.
    System.Boolean includeInactive

    If true, includes inactive Transforms in the search.
    Returns
    Type Description
    Transform[]

    An array of Transforms that match the filter condition. Returns an empty array if no matches are found.
    Examples
    // Find all transforms whose name contains "Hand".
Transform[] hands = rootTransform.FindInHierarchy(
    t => t.name.Contains("Hand")
);

    Parameters
    Type Name Description

    The Transform from which the raycast originates.
    Vector3 localDirection

    Direction in local space (e.g. Vector3.up, Vector3.forward).
    RaycastHit hit

    The RaycastHit object that will store information about the hit.
    LayerMask includedLayers

    The layers to include in the raycast.
    Vector3 localRayOffset

    Optional local space offset applied to the ray's origin.
    System.Single maxDistance

    The maximum distance for the raycast. Defaults to float.MaxValue.
    QueryTriggerInteraction queryTriggerInteraction

    Specifies whether the raycast should interact with trigger colliders.
    System.Boolean drawRay

    Whether to draw the ray in the scene for debugging purposes.
    Returns
    Type Description
    System.Boolean

    True if the raycast hits an object; otherwise, false.
    Remarks

    Direction and origin offset are transformed into world space internally.

    Examples
    RaycastHit hit;
if (transform.RaycastDirection(
    Vector3.up,
    out hit,
    LayerMask.GetMask("Default"),
    maxDistance: 10f))
{
    Debug.Log("Hit object above transform: " + hit.collider.name);
}
